# 🐱 喵星人咖啡屋

一款治愈系猫咪收集经营游戏，在这里你可以收养可爱的猫咪，经营属于自己的猫咖，与猫咪们建立深厚的羁绊～

## ✨ 游戏特色

- 🐾 **35种猫咪品种** - 从常见的橘猫到稀有的孟加拉豹猫，收集各种可爱的猫咪
- 🏠 **区域布置** - 大厅、猫爬架、窗边三大区域，根据猫咪性格合理安排位置
- ☕ **经营猫咖** - 招待客人，研发菜品，赚取金币和声望
- 📖 **专属故事** - 与猫咪好感度达到100%，解锁它们的专属感人故事
- 🎨 **精美界面** - 温馨治愈的UI设计，沉浸式的游戏体验
- 💾 **自动存档** - 游戏进度自动保存，随时继续你的猫咖之旅

## 🎮 游戏玩法

### 🐱 猫咪系统

- **收养猫咪**：在商店中使用金币收养各种品种的猫咪
- **性格搭配**：每只猫咪都有独特的性格（黏人、活泼、安静、高冷、慵懒、独立）
- **区域安排**：将猫咪放到适合它们性格的区域，获得心情加成和店铺buff
- **提升好感**：抚摸猫咪、使用零食玩具、让猫咪在店内工作

### ☕ 经营系统

- **招待客人**：点击客人选择菜单进行招待，赚取金币
- **菜品研发**：使用金币研发新的咖啡和甜点品种
- **猫咪加成**：开心的猫咪会为店铺提供各种加成
- **稀有客人**：高冷猫咪能吸引更多稀有客人，获得更高小费

### 🛒 商店系统

- **猫咪收养**：购买新品种的猫咪
- **店铺升级**：扩展区域容量，提升店铺设施
- **零食玩具**：购买猫咪零食，快速提升好感度

## 🎯 猫咪性格与区域匹配

| 区域 | 适合性格 | 店铺加成 |
|------|----------|----------|
| 🏠 大厅 | 黏人、活泼 | 吸引力、小费加成 |
| 🏔️ 猫爬架 | 高冷、独立 | 稀有客人、服务效率 |
| 🌅 窗边 | 安静、慵懒 | 客人耐心、客单价 |

## 🚀 快速开始

### 方式一：直接打开

直接用浏览器打开 `index.html` 文件即可开始游戏。

### 方式二：本地服务器（推荐）

使用 Python 启动本地服务器：

```bash
python3 -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000`
